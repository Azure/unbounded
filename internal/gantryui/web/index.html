CLUSTER-WIDE CLEANUP

Delete demos and reclaim disk space

This stops and deletes all dashboard-managed demo DaemonSets and their Pods in , then prunes unused images on every Flex worker in the configured pool.

Gantry, snapshotters, other workloads, and registry images are preserved. Active or uncertain runtime leases remain protected; reclamation is not a full disk wipe. Workers with stuck terminating demo Pods must recover before cleanup starts.

ON-DEMAND DEMO IMAGE

Generate. Push. Watch it pull.

Create unique random payload layers, push the image to ACR, then start one Pod per Flex worker.

When checked, convert this image to ACR Artifact Streaming before starting worker pulls. Requires a Premium ACR and streaming-enabled workers. Unchecked creates a regular OCI image.

MB means 1,000,000 bytes. Random payloads do not compress away. A small runtime base adds another layer and keeps the Pods running. Existing workloads are not removed.

Workers need space for both stored layers and unpacked files, roughly twice the payload for these ordinary OCI images.
