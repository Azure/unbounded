node routes configured registries through http://127.0.0.1:5000 using
containerd's certs.d configuration before expecting Gantry traffic.

Verify one agent:
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/name=gantry

Uninstall Kubernetes resources:
  helm uninstall {{ .Release.Name }} --namespace {{ .Release.Namespace }}

Containerd routing is externally managed and is not changed during uninstall.
