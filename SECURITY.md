# Security Policy

## Supported Versions

Unbounded Kubernetes is in early development. Security fixes are applied to the
latest release and the `main` branch. Older releases are not routinely supported.
Users should upgrade to the latest available release before reporting a problem
that may already have been corrected.

## Reporting a Vulnerability

Do not report suspected vulnerabilities through public GitHub issues,
discussions, or pull requests. Use the Microsoft Security Response Center
reporting process linked below and include:

- The affected component and version or commit.
- Reproduction steps and the expected security boundary.
- The observed impact and any known mitigations.
- Whether the report or related details have already been disclosed.

Reports are handled through Microsoft's security response process. Public
disclosure and release coordination are determined with the reporter after the
issue has been investigated. This repository does not publish private response
contacts, credentials, or operational security procedures.

## Security

Microsoft takes the security of our software products and services seriously, which
includes all source code repositories in our GitHub organizations.

**Please do not report security vulnerabilities through public GitHub issues.**

For security reporting information, locations, contact information, and policies,
please review the latest guidance for Microsoft repositories at
[https://aka.ms/SECURITY.md](https://aka.ms/SECURITY.md).
