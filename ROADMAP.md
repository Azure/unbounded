# Roadmap

This roadmap describes the intended direction of the project. It is not a
commitment to specific delivery dates and will evolve based on contributor
and adopter feedback.

## Current focus

### Multi-provider machine provisioning - In progress

- Provider-specific infrastructure resources
- Secure machine enrollment
- Machine lifecycle integration
- Initial provider implementations

### Cross-cloud Kubernetes networking - In progress

- Multi-region and multi-provider connectivity
- Routing scalability
- Failure recovery
- Network observability

## Next

### GPU capacity integration - Planned

- Capacity discovery
- GPU-aware provisioning
- Neo-cloud provider integrations
- Workload placement across providers

### Operational maturity - Planned

- Upgrade and repave workflows
- Security assessment
- Scalability testing
- Additional adopter documentation

## Longer-term direction

- Additional infrastructure providers
- Storage and image distribution optimizations
- Policy-driven workload placement
- Progress toward CNCF Incubation requirements

## Roadmap process

Roadmap changes are proposed through GitHub issues or pull requests.
Maintainers prioritize items based on adopter feedback, contributor
availability, architectural alignment, and CNCF ecosystem integration.

Detailed implementation work is tracked through GitHub issues and milestones.
